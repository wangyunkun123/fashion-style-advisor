# 开发日志 2026-06-19

## 管线优化日 — 7 项改进

### 1. 进度展示精简
- 每步从"进行中+完成"双消息 → 单消息 + `step_done()` 自动打 ✅
- 新增预估：`📊 预计 ~60-100s · ~N tokens`（依据 prompt 字符数动态计算）
- 完成只显示统计（`⏱️ 95s · 📊 7500 tokens · 🔄 2次AI`），移除排版图和文字摘要
- 前端 `pollTask()` 去 `d.image_url` 和 `d.result` 渲染，新增 `.step-estimate` CSS
- 5 步变 10 条消息 → 5 条消息 + 1 条预估 + 1 条统计

### 2. 管线瘦身（5步 → 3步）
- 移除 `composite_v2.py` 排版合成（微信推送已暂停，Hero 优先用 AI 原图）
- 移除 `build_push.py` 调用及 fallback `push_wechat`
- 合并 git push + 重建原型为一步 `📤 推送 + 刷新`
- 移除 `find_latest_composite()` 改用 `generate.py` 输出
- 移除 `format_outfit_summary()` 函数及 `CAT_EMOJI_EXTRA`
- 代码净减少 53 行，管线预估 -30s

### 3. 配件规则场景化
- 旧：`酌情添加（不是必须）` → AI 理解为不加，近 8 套中 7 套只有 3 件
- 新：`按场景需要选择，有理由才加，不铺满全身` + 举例说明
  - 功能型：运动/户外→帽+包，晴天户外→墨镜，寒冷→保暖
  - 点睛型：商务/正式→手表/手串 1 件即可
  - 日常休闲：0-1 件，不强制
- 措辞强调「举例非穷举，根据实际场景灵活判断」

### 4. 面料规则去 blanket
- 旧：`优先棉/麻/亚麻等亲肤面料` → 排除 48 件（63% 单品）
- 新：`面料匹配场景：夏季上衣→透气(棉/麻/速干)，运动→速干，下装/鞋/配件不受面料限制`
- 只约束上衣，场景决定面料

### 5. Seedream 表情控制
- 摄影指导新增 `表情: natural relaxed expression, slight smile or soft neutral`
- seedream_prompt 要求：`😊表情必须自然松弛（slight smile或relaxed neutral），严禁死板面瘫脸`
- Path A/B 两处同步更新

### 6. Pass 2 阈值优化
- 旧：只要有 1 件配件就跑 Pass 2
- 新：1 件配件 → 并入 Pass 1（5 张参考图，省一轮 API ~30s）；2+ 件 → Pass 1 + Pass 2

### 7. 死代码清理
- 删除：`build_narrative_prompt()` / `run_unified_pipeline()` / `run_unified_pipeline_v1()` / `main()` + `import sys`
- 496 行，文件 2346 → 1848 行
- 手机端只走 `build_enhanced_prompt()` 单一入口

### 8. 质量检查对齐

- 「Path A/B」提法废弃，改用函数名指代

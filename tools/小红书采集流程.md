# 小红书采集流程

## 前置条件
- `pipx install xiaohongshu-cli`（已装）
- 首次需扫码登录：`xhs login --qrcode`

## 三步流程

### 1️⃣ 搜索
```bash
xhs search "<关键词>" --json > /tmp/search.json
```
→ 从输出中获取 `note_id` 和 `xsec_token`

### 2️⃣ 读取详情
```bash
xhs read <note_id> --json > /tmp/note.json
```
→ 提取：`desc`（文案）、`interact_info`（互动数据）、`tag_list`（标签）、`image_list`（图片）

### 3️⃣ 写入百科
打开 `styles_universal/<style_id>/encyclopedia.md`，在「📕 小红书社区经验」章节新增条目：
```
### 👤 作者名 — 《标题》
> 综合热度: ❤️ 点赞  👍 收藏  💬 评论

**核心观点**: ...

**经验要点**:
- ...
```
底部更新「社区共识总结」表格。

## 注意
- 图片防盗链无法直接下载，查看需在浏览器打开帖子原文
- Cookie 过期后重新 `xhs login --qrcode`
- 每步间隔 2-3 秒避免触发风控

# 网球风 (Tenniscore)
> **状态**: `reviewed` | **最后更新**: 2026-06-13

## 📖 概述
Tenniscore（网球风）是将经典网球美学融入日常穿搭的风格，位于 **运动休闲与「静奢风」的交汇点**。白色 Polo 衫、百褶裤、奶油色短裤和一尘不染的白色球鞋是其基石。2024 年，Luca Guadagnino 执导、Zendaya 主演的电影《挑战者》（Challengers）成为该风格爆炸式出圈的文化催化剂——Jonathan Anderson（Loewe 创意总监）担任服装设计，将网球运动员的「工作服」和「生活服」无缝融合，让全世界知道了 Tenniscore。

## 📜 历史文化
- **1920s 起源**：René Lacoste 在网球场上发明了现代 Polo 衫（短袖、翻领、棉质珠地网眼），取代了当时运动员穿的长袖衬衫。
- **1950s Fred Perry**：英国网球冠军 Fred Perry 以自己的名字创立品牌，月桂花环 Logo 的 Polo 衫成为英伦亚文化（Mod、Skins）的标志。
- **1970s–1980s 网球时尚高潮**：Björn Borg 和 John McEnroe 的赛场穿搭成为流行文化符号；Ralph Lauren 从 2006 年起成为温网官方赞助商，进一步巩固了网球美学与上流社会的关联。
- **2024 爆发**：《挑战者》电影上映 + Zendaya 的宣传造型（网球鞋跟、球拍刺绣礼服）在社交媒体病毒式传播。Google 搜索 "tenniscore" 在 2024 温网期间飙升 286%。
- **2025 持续升温**：Lacoste 在巴黎时装周 FW 2024/25 推出 Tenniscore 系列，Gucci 为 Jannik Sinner 造型，运动休闲市场预计 2025 年达到 5174.8 亿美元。

## 🎨 美学特征
| 类别 | 核心单品 |
|------|---------|
| **上装** | **Polo 衫**（白色/浅色，翻领，珠地棉）——绝对基石；绞花针织 V 领背心；牛津衬衫 |
| **下装** | 中长百褶短裤（白色/奶油色）、定制西裤（将 Polo 从白天过渡到晚装）、网球短裙（女性向） |
| **鞋履** | **纯白运动鞋**（皮面网球鞋或极简主义跑鞋，一尘不染）；也可用乐福鞋/船鞋替代以增加优雅感 |
| **配饰** | 飞行员太阳镜、经典腕表、中筒袜（带条纹/纹理）、网球头带 |
| **外搭** | 绞花针织毛衣（披肩搭法/系在肩上，preppy 信号）、轻薄风衣 |

**色彩**：白色 + 海军蓝 + 森林绿 + 奶油色 + 淡黄 + 浅天蓝。整体干净、清爽、克制。

**核心规则**：「就像你刚打完网球，随手披上一件好看的毛衣，短裤还没换下来——这就是夏天的男装造型。」——Daniel-Yaw Miller（BoF）

## 🔗 关联风格
- **Preppy / Ivy League** — Tenniscore 与常春藤 prep 风格共享 Polo 衫、绞花毛衣和奶油色裤装
- **Quiet Luxury（静奢风）** — 克制、干净、不张扬的高品质服饰，Tenniscore 是运动版本的静奢
- **Athleisure（运动休闲）** — 与 Tenniscore 高度重叠，后者更偏向特定运动的审美提炼
- **Gorpcore** — 虽然逻辑不同（户外机能 vs 球场优雅），但共享「功能性服饰日常化」的思维方式

## 💡 穿搭建议
1. **入门公式**：白色 Polo 衫 + 奶油色/白色中长百褶短裤 + 纯白皮面运动鞋 → 零风险
2. **进阶公式**：将短裤换为定制西裤 + 乐福鞋 → Polo 从球场到酒吧的变身
3. **叠穿技巧**：绞花 V 领针织背心套在牛津衬衫外面，或把针织毛衣披在肩上（系结）
4. **品牌入门**：Uniqlo Polo + Sporty & Rich 短裤 + Lacoste 鞋；进阶：Casablanca Polo + Brunello Cucinelli 长裤
5. **关键禁忌**：不要穿脏鞋——Tenniscore 的核心是「一尘不染」

## 单品标注合成工具 `tools/composite.py`
**功能**：将 AI 效果图与原始单品图合成，在身体对应位置贴缩略图+标签

**迭代过程**：
1. v1：缩略图居中覆盖 → 遮挡面部，尺寸太小
2. v2：边缘布局（左/右/底），帽子移到左侧头部区域，放大缩略图（200-340px）
3. v3：尺寸分级（外套340 > 上衣/裤子/鞋320 > 包280 > 帽240 > 袜200 > 墨镜160），EXIF自动旋转，墨镜右侧头部

**用法**：
```bash
python3 tools/composite.py [穿搭目录]  # 默认最新
```

## 衣橱图片方向修正

### 问题
76 件服装图片中 57 张为横图（iPhone 横拍），标注图展示时方向错乱

### 解决
1. **`tools/fix_orientation.py`**：轻量工具，EXIF校正 + 横图转竖（顺时针90°）。测试发现绝大多数方向反了
2. **全部翻转180°**：修正旋转方向错误
3. **`tools/auto_orient.py`**：核心工具，调用豆包视觉模型自动判断每件衣服的真实朝向（上/下/左/右），精确旋转修正

### API 踩坑
- 初始尝试 `doubao-1.5-vision-pro-32k` → 401 无权限
- 用户提示 `doubao-seed-2.0-code` → 需用 `/api/plan/v3/chat/completions` 端点
- 该模型有推理 token 消耗，max_tokens 需设 ≥1000 避免输出被截断
- 解析模型输出需正则匹配结论句，避免"左右展开""上下颠倒"等描述词干扰

### 结果
- 76 件中 74 件 AI 自动修正成功
- 2 件墨镜（IMG_8586 / Image_20260610_0845_19_011）模型始终无法判断，待手动确认

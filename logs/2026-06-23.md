## 一、Bug 修复

### 1.1 日推管线失败：`name 'sys' is not defined`
- **根因**：`tools/unified_pipeline.py` 多用户改造时新增了 `sys.argv` / `sys.path` 调用，但 import 漏了 `sys`
- **修复**：`import json, os, re, sys, time` 补充 `sys`
- **影响**：凌晨 06:27 和早上 09:11 两次日推均失败
- **Commit**：`cc6a909`

### 1.2 CDN URL 指向旧 commit
- **根因**：`get_git_commit()` 有内存缓存，`git push` 后未刷新 → 原型 CDN URL 指向旧 commit 无图片
- **修复**：新增 `invalidate_git_commit_cache()`，`_background_push()` 在 `git push` 成功后自动刷新缓存
- **Commit**：`d8fe7fa`

### 1.3 探索 IIFE 自加载导致主用户/becca 无法操作
- **根因**：探索页自加载代码（`loadExploreTweak();setTimeout(...)`）+ API URL `?user=` 注入在某些情况下触发 JS 错误
- **修复**：回退到旧版 `setTimeout(loadExploreTweak, 100)` 模式，保留渲染功能（折叠/分组/缩略图）
- **Commit**：`413a106`

### 1.4 Tailscale Funnel 502
- **根因**：Funnel 重建时使用了错误的 `https+insecure://` 协议
- **修复**：`tailscale serve reset` → `tailscale serve --bg http://127.0.0.1:8765` → `tailscale funnel --bg http://127.0.0.1:8765`
- **Commit**：N/A（基础设施操作）

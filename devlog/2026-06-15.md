# 开发日志 2026-06-15

## 手机控制台 5 Tab 完整建设

### 背景
手机控制台原只有「推荐」页完整，其余 4 个 Tab 均为占位符。今日完成全部页面建设。

### 页面结构
```
🧠 推荐 — Hero图+单品清单+历史+输入框
🧪 探索 — 4子页：微调/转换/跨界/趋势
👔 衣橱 — 4子页：品类网格/月度报告/闲置/缺口
➕ 添加 — 拍照/上传→AI识别→确认入库
⚙️ 我的 — 推送偏好/身形档案/使用统计
```

### 新增 API 端点（11个）

| `GET /api/wardrobe/items` | 76件单品列表含缩略图 |

### 修复的 Bug
1. Tab 图标消失 — key 名不匹配（`rec→recommend` 等）
2. Tab 切换失效 — `data-page` 值与页面 ID 不匹配
3. JS 语法错误 — 多余 `}}` 导致整个 script 块失效
4. 单品列表不可滚动 — 缺少 `overflow-y:auto`
5. CSS 未注入 — 模板替换位置错误

### 关键架构决策
- **统计数据前端 JS fetch**（非 build 时注入），保证实时性
- **build_prototype.py** 扫描 outfits/ 目录动态注入 Hero/单品/历史数据
- **CSS/HTML 结构分离**：确认版排版只改数据源，不动结构

### Hero 图规则
- 优先 AI 原始生图 `上身效果_1.png`
- 不用排版图或形象图
- 每次生成新穿搭后必须运行 `build_prototype.py` 重建原型

### 核心文件
- `tools/build_prototype.py` — 原型构建器（扫描+动态注入）
- `tools/wechat_control.py` — 新增 11 个 API 端点 + 衣橱解析函数
- `prototype/mobile-v2.html` — 自动生成（197KB）
- `prototype/icons-set.html` — 83个自定义图标库预览
- `memory/wechat-remote-control.md` — 远程控制文档
- `memory/hero-image-rule.md` — Hero 图规则

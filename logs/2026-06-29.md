# 开发日志 2026-06-29

## 产品方向大讨论：从"衣橱管理"到"穿搭微调教练"

### 问题提出

kun 发现了一个严重的产品问题：衣服上传这一步会打消大部分用户兴趣。逐件上传对于有 100+ 件衣服的用户来说需 5-10 小时，拍上身照 AI 识别又太不稳定。

### 第一轮探索：三个方向（A/B/C）

- **方向 A（衣橱数字化）**：用技术创新解决录入问题（电商导入/视频扫描/品牌数据库）
- **方向 B（风格引擎）**：放弃衣橱数据，直接推荐穿搭 + 购买链接
- **方向 C（混合路线）**：B 获客 + A 深化

**结论**：三个方向都被否决——
- A：录入问题无法根本解决
- B：同质化严重，大厂已在做
- C：产品不聚焦，没亮点

### 第二轮探索：五个新方案

| 方案 | 核心 | 结果 |
|------|------|------|
| 今日穿搭日记 | 每天拍照 AI 点评 | ❌ 通用 AI 对话可替代 |
| 风格克隆 | 截图博主穿搭→在自己身上重现 | ❌ 仍需衣橱数据 |
| 穿搭挑战 | 每日创意限制 + 打卡 | ❌ 小红书可替代 |
| AR 试穿镜 | 镜中实时换穿 | ❌ 技术不可行 |
| 每天一套（Tinder 式） | 左滑右滑选穿搭 | ❌ 好玩但不解决真实需求 |

### 关键转折：时尚最后一公里

kun 提出核心洞察：

> 市面上的穿搭产品都在教用户"穿什么衣服"，没人教"怎么把衣服穿好"。同一个白衬衫，塞不塞、卷不卷——这正是普通人的时尚盲区。选择我们产品的用户都懂基本穿搭，和时尚的差距就在这些微小的技巧上。

**产品定位转变**：
```
旧：你该穿这件 + 那条裤子  → 教买什么
新：衬衫解开两颗扣+袖口卷两圈 → 教怎么穿
```

### 第三轮收敛：穿搭技巧教练

三个产品概念的融合：
1. **微调**：拍照 → AI 审稿 → 微调建议 → 效果图对比 → 打卡
2. **点睛**：技巧树 × 每日一练 × 等级系统
3. **穿对**：同一套衣服两种穿法的效果对比

### 产品逻辑定调：三层递进

```
Layer 1（学会穿）：拍照 → AI微调 → 对比 → 打卡
  → 用户获得穿搭技巧 + 肉眼可见的进步
  → 产品获得身形+衣橱+风格偏好数据
  → Day 1-30

Layer 2（帮你穿）：数据够了 → AI每日推3套方案
  → 左滑右滑 → 越用越准
  → Day 30+

Layer 3（聪明买）：衣橱缺口 → 精准单品推荐
  → "你缺这件来完成你的风格"
  → Day 60+
```

### 关键决策

- 产品方向：从"衣橱管理工具"转型为"穿搭微调教练"
- 核心原则：不教用户买什么，教用户怎么穿
- 数据策略：零录入启动 → 被动衣橱数字化 → 渐进式用户体验升级
- 差异化壁垒：结构化技巧课程 + 身形建模效果图 + 习惯养成引擎（这些通用 AI 对话做不到）
